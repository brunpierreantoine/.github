# GitHub Defaults

Public account-wide community files and reusable automation for repositories
owned by `brunpierreantoine`.

Public visibility is intentional: GitHub only applies account-level community
defaults from a public `.github` repository. This repository must never contain
secrets, private project details, account IDs, or confidential content.

## Included

- Default contribution, support, security, issue, and pull-request guidance.
- Reusable Bun/TypeScript CI workflow with least-privilege permissions.
- Dependabot updates for GitHub Actions.

Projects keep small caller workflows locally so their checks and permissions stay
visible. Application-specific deployment logic remains in each private project.
